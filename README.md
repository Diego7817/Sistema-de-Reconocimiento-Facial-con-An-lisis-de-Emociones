# Sistema de Reconocimiento Facial con Análisis de Emociones

## Descripción
Sistema completo de reconocimiento facial en tiempo real con capacidad para identificar personas y analizar 7 emociones básicas.

## Características
- Registro de personas con captura facial
- Reconocimiento facial en tiempo real
- Clasificación de 7 emociones (Felicidad, Tristeza, Enojo, Sorpresa, Neutral, Miedo, Disgusto)
- Interfaz gráfica intuitiva
- Base de datos SQLite
- Reportes y estadísticas
- Exportación de datos
